# MASTER CURRICULUM — Full Subject Map

This is the complete map of everything the curriculum tackles, from Stage 0 to the open end.
It is a MAP, not a prison: ordering is dependency-driven, hours are estimates not deadlines,
and detailed lessons are created one at a time as the learner progresses.

Current position is tracked in [notes/curriculum_state.md](../notes/curriculum_state.md).

---

## Continuous Threads (run across ALL stages, taught in context)
- Security (input validation → web security → AI security)
- Testing (from simple checks → unit tests → CI)
- Debugging (error reading → print debugging → profilers)
- Git & GitHub practice
- Mathematics (just-in-time, tied to technical need)
- AI collaboration (Level 1 basic assistance → Level 5 professional AI engineering)
- Systems thinking (code → runtime → OS → network → cloud → distributed → AI)

---

## STAGE 0 — Foundations (~130–160 hours)
Goal: establish the learning loop; real programming ability; math floor.

1. Learning How to Learn (evidence over claims, the verification loop, doing-is-learning)
2. Algebra & Functions (variables, equations, expressions, f(x))
3. Logic (truth tables, and/or/not, implication, logical reasoning)
4. Discrete Foundations (sets, combinatorics, sequences)
5. Programming Fundamentals — Python:
   - variables, data types, arithmetic, strings
   - conditionals & boolean logic
   - loops (while, for, range)
   - functions (parameters, return, scope)
   - lists & basic data structures
   - errors & exceptions
   - file I/O
6. Terminal / Command Line (navigation, file operations, running programs)
7. Git & GitHub (init, add, commit, push, branches, remotes)
8. Testing & Debugging Basics (predict-then-verify, reading tracebacks)

## STAGE 1 — Programmer / Problem Solver (~160–200 hours)
Goal: algorithmic thinking; strong Python; tools fluency.

1. Data Structures (lists, stacks, queues, linked lists, hash tables, sets, dictionaries, trees, graphs)
2. Algorithms (searching, sorting, recursion, two pointers, greedy, dynamic programming)
3. Complexity Analysis (Big-O, space/time tradeoffs)
4. Object-Oriented Programming (classes, inheritance, encapsulation)
5. Error Handling & Exceptions (try/except, raising, logging)
6. Testing (pytest, unit tests, test-driven approach)
7. Debugging Mastery (systematic isolation, hypothesis-driven)
8. Introductory Probability (sample spaces, independence, expected value)
9. Git Workflows (branching, merging, collaboration)

## STAGE 2 — Junior Builder (~200–260 hours)
Goal: build real applications; database + web fundamentals; linear algebra.

1. Databases & SQL (modeling, queries, joins, indexing, transactions)
2. Web Fundamentals (HTTP, request/response, HTML, CSS)
3. JavaScript & the DOM (for real frontend capability)
4. Frontend Development (responsive design, components)
5. Backend Development (Flask/FastAPI, REST APIs, JSON)
6. Authentication & Authorization (sessions, tokens, hashing, OAuth basics)
7. Linear Algebra Foundations (vectors, matrices, dot products, transformations)
8. Deployment Basics (servers, environments, hosting)
9. First Serious Projects (2–3, portfolio-worthy)
10. Initial Freelance Readiness (requirements, estimates, communication)

## STAGE 3 — Software / Full-Stack Professional (~260–320 hours)
Goal: production-grade engineering; employability.

1. Production Full-Stack Applications (architecture, error handling, UX)
2. Advanced Backend (middleware, rate limiting, background jobs, caching)
3. Web Security (XSS, CSRF, SQL injection, secrets management)
4. Deployment & Operations (Linux, Docker, cloud basics, process management)
5. CI/CD (automated build, test, deploy pipelines)
6. Observability (logging, monitoring, alerting)
7. System Design Fundamentals (scaling, caching, queues, tradeoffs)
8. Testing at Scale (integration tests, test environments)
9. Calculus (derivatives, integrals, optimization intuition)
10. Capstone Project (production-like, documented, deployed)
11. Job & Freelance Readiness (portfolio, resume, interviews)

## STAGE 4 — AI-Native Engineer (~220–280 hours)
Goal: build reliable AI systems on a real engineering base.

1. LLM APIs (prompting, structured output, context management)
2. Embeddings (what they are, how to use them)
3. Retrieval & RAG (chunking, vector stores, search, citations)
4. Agents & Tool Calling (planning, tools, memory, loops)
5. Evaluation (metrics, evals, regression testing for AI)
6. AI Reliability (hallucination control, fallbacks, validation)
7. AI Security (prompt injection, tool abuse, data leakage, agent permissions)
8. AI Product Architecture (multi-agent systems, cost/latency design)
9. Context Engineering & AI Workflows (agentic dev practices)
10. AI Projects (2–3 production-like AI applications)

## STAGE 5 — ML / Applied AI Specialist (~260–320 hours)
Goal: real machine learning depth on top of the engineering + math base.

1. Probability & Statistics (distributions, inference, hypothesis testing)
2. Linear Algebra Deep (eigenvalues, SVD, applications)
3. Calculus & Optimization (gradients, descent algorithms)
4. Classical ML (regression, classification, clustering, decision trees, ensemble methods)
5. Neural Networks & Deep Learning (architecture, training, regularization)
6. Model Training & Fine-Tuning (datasets, GPUs, transfer learning)
7. Model Evaluation (metrics, validation, baselines, failure analysis)
8. MLOps (pipelines, serving, monitoring, drift)
9. ML Projects (end-to-end, deployed)

## STAGE 6 — Advanced Technical Professional (~220–280 hours)
Goal: depth + scale; independent technical judgment.

1. Distributed Systems (consistency, replication, consensus, queues)
2. Advanced Architecture (microservices vs monolith, event-driven, data flow)
3. Advanced Security (threat modeling, hardening, audit)
4. Scalability & Reliability (SLOs, load, failure modes)
5. Specialization Depth (chosen area: AI systems, ML, systems, security, data)
6. Technical Communication (design docs, code review, mentorship)

## STAGE 7 — Open-Ended Branches
After the core stages, specialization is chosen by evidence, interest, and market:

- ML / AI Research
- AI Security
- Cybersecurity
- Data Engineering
- Cloud / Platform Engineering
- Quantitative Computing
- Robotics / Embedded
- Systems Engineering
- Technical Leadership
- Technical Entrepreneurship

## Notes on the Map
- Stages OVERLAP by design: AI concepts may appear earlier as previews; deep specialization does not.
- Mathematics is just-in-time: algebra now, probability in Stage 1, linear algebra in Stage 2, calculus in Stage 3, deep stats in Stage 5.
- Every substantial topic produces three files: Full Lesson, Cheat Sheet, Advanced (optional).
- Progress is measured by demonstrated capability, never by file count or course completion.
