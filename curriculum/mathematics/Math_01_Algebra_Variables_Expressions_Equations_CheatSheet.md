# Math Day 1 Cheat Sheet — Variables, Expressions, Equations

## Vocabulary
- Variable = named box for a number: `x`
- Coefficient: the number in front — `2x` = two x's
- Constant: plain number — `2x + 3` has constant 3
- `x` alone = `1x`
- Expression: phrase, no "=" — has a value once x is known
- Equation: sentence with "=" — asks "for which x?"

## Balance rule (THE method)
> Same operation on both sides. Always.

## Solving one-step
```
x + 5 = 12   →  x = 7    (subtract 5 both sides)
x - 4 = 9    →  x = 13   (add 4 both sides)
3x = 21      →  x = 7    (divide by 3 both sides)
x / 5 = 6    →  x = 30   (multiply by 5 both sides)
```

## Checking (always!)
```
x + 5 = 12, solution x = 7 → check 7 + 5 = 12 ✓
3x = 21, solution x = 5    → check 3·5 = 15 ✗ WRONG
```

## Like terms
- Same letter = same kind = can combine: `3a + 2a = 5a`, `2x + 3 + 4x + 1 = 6x + 4`
- Different kinds never combine: `2x + 3` stays `2x + 3`
- `2x` = x + x (NOT x·x — that's x²)

## Word problems
- "a number" → x
- "more than / sum / plus" → +
- "spent / less than / minus" → −
- "times / product / of" → ×
- "is / equals" → =
